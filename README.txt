[가장 먼저 할 일]

1. Supabase 프로젝트에서 SQL Editor를 엽니다.
2. setup.sql 파일의 내용을 전부 복사해서 실행합니다.
3. 실행 결과 맨 아래에 "최초 관리자용 초대 코드"가 표시됩니다.
4. 그 코드를 복사합니다.
5. 이 사이트의 signup.html에서 본인 계정을 가장 먼저 가입합니다.
   - 이 최초 코드를 사용해 가입한 계정은 자동으로 관리자 계정이 됩니다.
6. 관리자 계정으로 로그인한 뒤 admin.html에서 일반 유저용 일회용 초대코드를 발급할 수 있습니다.

[중요]

- setup.sql의 초대코드 검증은 DB 트리거에서 실행됩니다.
  즉, 프론트엔드에서 회원가입 버튼을 우회해도 유효한 초대코드 없이는 auth.users 생성이 롤백됩니다.
- Publishable key는 브라우저에 들어가도 되는 공개용 키입니다.
- Secret key / service_role key / Database password는 절대로 GitHub에 올리지 마세요.
- 이메일 인증이 켜져 있으면 가입 후 메일 인증이 필요합니다.

[현재 들어간 기능]

- 초대 코드 전용 회원가입
- 로그인 / 로그아웃
- 최초 가입자 자동 관리자 승격
- 관리자 초대코드 발급
- 초대코드 1회 사용 / 만료 처리
- 기본 프로필 편집
- 공개 프로필 페이지(profile.html?u=주소아이디)
- RLS 기본 적용
